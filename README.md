# Gesundheits-Lexikon

Nachschlagewerk aus den WhatsApp-Gruppen „Gesundheit“ und „Psychologie“ – als mobile Webseite.

- Drei Bereiche: Gesundheit & Psyche · Spiritualität · Numerologie & Astrologie
- Videos mit Transkript, Artikel, Buch-Zusammenfassungen, Infografiken
- Suche, Themen, Merkliste, Teilen per WhatsApp, Deutsch / Русский

Das Lexikon sammelt Inhalte, die in den Gruppen geteilt wurden, und ersetzt keine ärztliche oder therapeutische Beratung.
